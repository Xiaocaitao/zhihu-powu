# 破雾成长空间模块分工

## 一、总体链路

```text
首页聊天
  → Agent Loop
  → Agent Tool
  → 业务模块 Service
  → 数据库
  → domain_update
  → 前端刷新成长空间
```

“成长空间”是页面分组，不单独建立一个 `growth` 大模块。每个业务域负责自己的数据和业务规则，首页负责聚合展示。

## 二、五人分工

| 负责人 | 对应页面 | 后端业务模块 | 主要职责 |
| --- | --- | --- | --- |
| 队长 | 首页、会话记录、知识库 | Agent/Core/Knowledge | Agent Loop、Tool 注册、知识库、首页聚合、聊天会话、SSE、最终集成 |
| 队员 A | 画像与规划 | Profile | 用户基础信息、兴趣、能力、时间、目标 |
| 队员 B | 职业规划、目标岗位 | Career | 职业方向、岗位要求、能力差距、岗位匹配 |
| 队员 C | 学习计划 | Learning Plan | 阶段计划、两周计划、学习任务、进度、反馈和调整 |
| 队员 D | 学习记录、模拟面试 | Evidence & Interview | 学习轨迹、项目成果、能力证据、面试记录和反馈 |

原型中的社区论坛、学习搭子、复杂企业数据和排行榜等功能暂不纳入第一版主链路。

## 三、模块职责

### 队员 A：Profile

对应页面：`画像与规划`

负责：

- 学校、专业、年级；
- 已学内容和当前基础；
- 兴趣方向；
- 每周可投入时间；
- 学习偏好；
- 目标方向；
- 画像完善度。

建议能力：

```text
get_user_profile
save_profile_fact
update_user_goal
get_profile_completion
```

### 队员 B：Career

对应页面：`职业规划`、`目标岗位`、原型中的`就业成长`

负责：

- 职业方向分析；
- 目标岗位和目标企业；
- 岗位能力要求；
- 用户能力差距；
- 岗位匹配分析；
- 推荐行动；
- 职业规划版本。

建议能力：

```text
get_career_plan
create_career_plan_draft
get_target_jobs
analyze_job_gap
confirm_career_plan
```

### 队员 C：Learning Plan

对应页面：`学习计划`，以及`体验中心`中的任务视图

负责：

- 阶段学习计划；
- 两周学习计划；
- 今日任务；
- 任务状态；
- 任务预计时间；
- 学习进度；
- 任务拆分；
- 根据反馈调整计划。

建议能力：

```text
get_active_learning_plan
create_learning_plan
update_learning_task
record_learning_feedback
adjust_learning_plan
```

### 队员 D：Evidence & Interview

对应页面：`学习记录`、`模拟面试`

负责：

- 学习时间线；
- 学习成果；
- 阶段测验；
- 项目成果；
- 能力证据；
- 面试会话；
- 面试题目和回答；
- 面试反馈。

建议能力：

```text
get_learning_records
record_learning_evidence
get_skill_evidence
start_interview
submit_interview_answer
get_interview_feedback
```

### 队长：Agent/Core/Knowledge

对应页面：`首页`、`会话记录`、`我的知识库`

负责：

- `/api/chat`；
- Pi Agent Loop；
- Tool 注册和适配；
- Prompt 和可信上下文；
- Tool 调用顺序；
- Tool 错误和确认机制；
- 文件上传、解析、切分、索引和检索；
- 首页 `/api/home-summary`；
- 会话历史；
- SSE 和 `domain_update`；
- 最终联调和部署。

知识库建议能力：

```text
upload_knowledge_document
search_knowledge
get_knowledge_document
```

## 四、开发边界

每个队员负责自己的业务域，包括：

```text
数据表和 migration
Repository
Application Service
业务校验
状态流转
模块函数接口
Agent Tool 能力定义
单元测试
README
```

队员不直接修改：

```text
src/agent/runtime/
src/modules/chat/
Tool 总注册表
全局 SSE 协议
```

这些部分由队长统一控制。

## 五、核心联调链路

```text
用户描述自己的情况
  → 保存画像
  → 生成职业规划
  → 生成学习计划
  → 更新任务状态
  → 提交学习反馈
  → 调整计划
  → 首页显示最新状态
```
