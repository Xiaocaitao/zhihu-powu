# 队员 D：Evidence & Interview 开发计划

## 开发目标

围绕学习记录和模拟面试两个独立业务块，按已确认的需求文档与技术接口契约完成页面、后端能力和队长集成准备。阶段测试、学习计划调整、岗位匹配和主页面集成不属于本模块实现范围。

## 阶段一：独立页面

- 学习记录页面：时间线、成果、能力证据、阶段复盘、空状态和待验证状态。
- 模拟面试页面：训练范围、当前题目、回答区、进度、逐题反馈、结束面试和报告状态。
- 只做 HTML 结构与样式，使用占位符和少量 mock 场景，不接 API、不写固定用户数据。
- 交付两个可独立打开的 HTML 文件，供队长集成。

## 阶段二：学习记录后端

- 实现记录查询、成果保存、成果修正或撤回、证据评估、能力证据查询、阶段复盘生成和历史复盘查询。
- 完成记录、项目、证据、评估、复盘及操作幂等所需的模块基础能力。
- 通过 Learning Plan、Knowledge、Shared Skills 的端口读取外部数据，不直接读取其他模块的表。
- 阶段测试只引用 Learning Plan 的已有结果，不负责测试流程或评分。

## 阶段三：模拟面试后端

- 实现面试创建、面试恢复、逐题回答、逐题反馈、提前结束、整场报告、反馈查询和历史查询。
- 验证会话状态、版本、重复提交、回答不可覆盖、生成失败恢复和报告唯一性。
- 通过 Career、Profile、Knowledge 和学习记录能力获取训练上下文。
- 面试报告可输出改进建议，但不直接创建或修改学习任务。

## 阶段四：集成准备

- 提供 13 个 Agent Tool 的 capabilities 工厂、应用服务和端口说明。
- 提供迁移、测试、README、领域事件和页面接口映射，供队长接入。
- 队长负责主 Agent 注册、可信上下文、LlmInvoker、路由、domain_update 和主页面集成。

## 协作与提交规则

- 每个开发阶段开始前拉取并合并最新 `main`。
- 每个阶段完成后运行对应检查并创建包含需求描述的本地 commit。
- 不推送远程，推送前先提醒负责人并等待决定。
- 不推送到远程 `main`；后续如获授权，只推送 `dev-qianqi7777`。

## 阶段一验收

- 两个页面文件独立存在并可直接打开。
- 页面无 API 调用、无真实用户信息、无固定默认业务结论。
- mock 数据不重复，仅覆盖基本展示状态。
- 页面端不实现业务判断、题目生成、评分或计划调整。
